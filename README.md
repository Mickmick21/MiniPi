# MiniPi

Open-Source Minitel serial interface for Raspberry Pis.

## Compatibility

Raspberry Pi

| Model | Compatible | Recommended | Tested
| -------------- | - | - | -
| 3A+ | ✓ | ✓ | ✓
| Zero 2 W | ✓ | ✓ | ✗
| 3B+ | ✓ | ✓ | ✗
| 3B | ✓ | ✓ | ✗
| 4B | ✓ | ✓ | ✗
| 5 | ✓ | ✓ | ✗
| 2B | ✓ | ✗ | ✗
| 1B | ✓ | ✗ | ✗
| 1B+ | ✓ | ✗ | ✗
| 400 (Keyboard) | ✓ | ✗ | ✗
| 1A | ✗ | ✗ | ✗
| 1A+ | ✗ | ✗ | ✗
| Zero | ✗ | ✗ | ✗
| Zero W | ✗ | ✗ | ✗
| Zero WH | ✗ | ✗ | ✗

For Minitels, any Minitel with a DIN port *should* work.
